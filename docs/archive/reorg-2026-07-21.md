# Repo reorganisation — 2026-07-21

Split the experiment tree into **setup** (producing runs) and **analysis**
(interpreting them), and inverted the ignore policy so result data is tracked.
Branch: `refactor/experiments-analysis-split`.

## Layout

| Before | After |
|---|---|
| `scripts/experiments/<name>/` (configs + plots + figures mixed) | `scripts/experiments/setup/<name>/` — configs, launch/eval `.sh`, `README.md` |
| `scripts/plotting/<name>/` | `scripts/experiments/analysis/<name>/` — notebooks, findings, `data/`, `figures/` |
| `scripts/plotting/archive/` | `scripts/experiments/analysis/archive/` |
| `scripts/analysis/` (shared harness) | `scripts/harness/` |
| `scripts/experiments/eval/` | `scripts/eval/` |
| `.pptx` scattered across 8 experiment folders | `slides/<date>_<topic>/` |

`experiments/` at the repo root is **unchanged** — that is the training engine
(`trainer.py`, `params.py`, `sampler.py`), not per-experiment folders.

The two trees are name-aligned but independent: an experiment with no analysis
yet, or an analysis with no experiment folder, is normal. Findings files
(`RESULTS.md`, `FINDINGS.md`) live with the analysis; the `README.md` that
explains how to reproduce a run stays with the setup.

## Ignore policy

Previously `*.csv` and `*.png` were ignored wholesale and bypassed with
`git add -f`. Now the canonical folders are tracked and everything else is not:

- **Tracked:** `data/`, `figures/`, `archive/` under the analysis tree.
- **Ignored:** artifacts anywhere else, plus `run_logs/`, `ml_log_*.txt`,
  `model_list.txt`, `*.pptx`.

Because the blanket binary rules were also the de-facto size guard,
`.githooks/pre-commit` now rejects any file over 25 MB.

## Required once per clone

```bash
git config core.hooksPath .githooks
```

Not carried by `git pull`. Already configured on the laptop and on Tucker.
