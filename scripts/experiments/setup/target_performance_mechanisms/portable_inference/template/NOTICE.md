# Attribution and release status

The model implementations derive from the study's PRODIGY research checkout and
the PRODIGY method (Huang et al., "PRODIGY: Enabling In-context Learning Over
Graphs", 2023, https://arxiv.org/abs/2305.12600). Original model source comments
are preserved. Source-unit hashes and exact extraction rules are included.
PyTorch, PyTorch Geometric and torch-scatter are external dependencies with their
own licensing terms; they are not redistributed in this archive.

No repository-level license file was present in the inspected study checkout.
This local candidate therefore does not invent a license grant or assert that
the model code, checkpoints or derived datasets may be publicly redistributed.
Resolve upstream licensing and dataset rights before public release. The package
contains code and synthetic fixtures only; private feature tensors and trained
weights must be provided separately by an authorized holder.
