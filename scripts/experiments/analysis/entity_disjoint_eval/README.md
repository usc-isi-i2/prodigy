# Entity-disjoint evaluation

This analysis corresponds to
`scripts/experiments/setup/entity_disjoint_eval/`. It contains both the
episode-center diagnostic and the stronger induced-subgraph evaluation over the
three graph universes with full compatible Twitter IDs: Ukraine, Covid, and
Midterm.

Committed files are aggregate-only. Private ID tables and graph-row exclusion
indices remain under Tucker `state/` and are not publication artifacts.
