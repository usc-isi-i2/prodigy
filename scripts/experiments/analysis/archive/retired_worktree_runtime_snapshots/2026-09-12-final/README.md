# Final Tucker worktree runtime snapshots (2026-09-12)

This directory preserves 6,510 small machine-readable metric, configuration, and
provenance files (about 36 MiB) from the final Tucker retirement wave. Sources:

- `paper-all-pairs`: `log/paper_all_pairs/20260908/`;
- `paper-fast`: the seed-1 fast-ladder result tree;
- `flagship-recovery`: the recovery receipt;
- `paper-remainder-opt`: flagship and remainder metric trees;
- `vision-mixture-seeds`: seed-1/2 result trees;
- `walk-mini-pilot`: the COVID and Ukraine result JSONs.

Only JSON, JSONL, CSV, TSV, and YAML evidence from inspected experiment-specific
paths was copied. Checkpoints, tensors, caches, console logs, W&B directories, and
raw social-media examples were excluded. These files preserve reproducibility and
audit context; canonical conclusions and presentation-ready outputs live in the
active analysis directories.
