# Matched paper flagship ladders

This completed analysis joins the original seed-0 source-held-out intervention
campaign to matched seed-1/2 replicas. It contains 1,080 NM cells, 600 downstream
classification cells, and 432 capacity-comparison cells. The training seed is the
replication unit; shaded figure regions are observed ranges, not confidence intervals.

The headline decision uses both the final rung and normalized area over the full
eight-rung curve, with a 0.001 ROC-AUC practical threshold and target-safety gate.
