# Native-model result matrix

This folder is the cross-experiment coverage ledger for the native-pretext
comparison requested on 2026-08-25. `CLS` always means downstream node-label
classification. Neighbor matching is never relabeled as CLS.

## Eligibility boundary

Each learned family is admitted only under its registered native pretext:

| family | eligible pretext |
|---|---|
| PRODIGY | neighbor matching |
| VISION | label-free feature similarity |
| GILT | native label-free SSL still undefined |
| SAMGPT | GraphCL |
| GraphSAGE | pilot-v1 link prediction |

The common-neighbor-matching VISION/GILT experiment is an architecture control,
not evidence in this matrix. The existing so-called native GILT source sweep is
also excluded: inspection of its trainer shows target-label episodic
classification rather than self-supervision. No GILT cell is credited until a
genuine native SSL objective is specified and registered.

Legacy episodic static- and temporal-link-prediction scores are excluded. The
GraphSAGE pilot checkpoint remains eligible because it was trained with its own
pairwise link-prediction implementation, not the invalid PRODIGY evaluator.

## Files

- `data/coverage.csv` is the compact status table.
- `data/evidence_register.csv` records the scope, canonical evidence, eligibility
  decision, and compute regime behind every credited or excluded family.
- `figures/coverage.{png,pdf}` is generated by `plot_coverage.py`.
- `FINDINGS.md` is the human-readable audit and execution log.
- `FIGURE_INDEX.md` points to the canonical figures for every result family;
  existing figures are reused instead of copied.

Fixed-compute and convergence-trained results are separate evidence classes.
The current learned-model matrix is overwhelmingly fixed-compute. A missing
convergence-trained counterpart does not downgrade a fixed-compute cell, but it
also must not be implied by one.
