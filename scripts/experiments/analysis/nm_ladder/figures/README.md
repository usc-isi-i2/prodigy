# NM graph-ladder — figures

All figures for the 8-rung merged-graph NM ladder. Every one is regenerated by a
script in the parent folder; all of them write here (`figures/`, or the subfolder
noted below). Findings: [`../RESULTS.md`](../RESULTS.md).

Naming is `nm_ladder_<what>.<ext>` (ladder rungs) or `nmss_<what>.<ext>` (ladder rungs
combined with the single-source specialists from `../../nm_single_source_matrix/`).

## Layout

| where | what | script |
|---|---|---|
| `./` | trajectories, deltas, gain-vs-retention, gap-to-best, heatmaps, regret bars | `plot_nm_ladder*.py`, `plot_gain_retention*.py`, `plot_gap_to_best_means.py`, `plot_per_step_delta.py`, `plot_heatmaps.py` |
| `boxplots/` | per-model gap-to-best boxplots, ladder-only and ladder+specialists | `plot_ladder_delta_boxplot.py`, `plot_combined_delta_boxplot.py` |
| `2d_scatter/` | generalist-vs-specialist scatters (home-turf AUC vs breadth; regret axes; error bars) | `plot_generalist_scatter*.py`, `make_ladder_figures.py` |
| `similarity/` | donor quality vs graph-divergence statistics (in-/out-degree KS, separation, ρ by metric) | `plot_nm_ladder_vs_similarity.py` |

## Reading the main ones

- `nm_ladder_trajectory` — per-graph AUC across the 8 rungs; each graph steps up when
  it enters training.
- `nm_ladder_gain_retention` — one-panel, two-claim summary: incumbents hold (~.92–.96)
  while each newcomer jumps from its out-of-distribution level to its in-training level
  (ukr_susp +.16, cp_hk +.14 largest; covid/twibot20 ~flat — they already transfer).
  `_std` / `_minmax` are dispersion-band variants, `_gap*` the same recast as
  gap-to-best.
- `nm_ladder_gap_to_best_means` — mean gap to the best of all 16 models (8 rungs + 8
  specialists), in-training vs all 8. Converges to the residual generalist tax (−0.020).
- `boxplots/nm_ladder_delta_boxplot` — per-rung spread of that gap; boxes tighten and
  rise toward 0 as sources are added.
